# ============================================================================
#  Hermes Agent — Cấu hình cài đặt (config.txt)
# ============================================================================
#  File này được install.sh ĐỌC TỰ ĐỘNG khi cài đặt → cài đặt KHÔNG cần hỏi gì.
#
#  Vị trí file (theo thứ tự ưu tiên):
#    1. $HERMES_CONFIG            (biến môi trường, nếu bạn đặt)
#    2. cùng thư mục với install.sh   ← mặc định nên để ở đây
#    3. /data/hermes/config.txt
#
#  Định dạng:  KEY=VALUE  (mỗi dòng một biến)
#  Dòng bắt đầu bằng "#" là comment, sẽ bị bỏ qua.
#  Sau khi sửa xong, chạy:   bash install.sh
#
#  LƯU Ý sudo: nếu tài khoản cần mật khẩu sudo, các gói tùy chọn (ripgrep,
#  ffmpeg, build tools) sẽ được BỎ QUA âm thầm để không chặn quá trình chạy nền.
#  Khi đó hãy tự cài sau:  sudo apt install -y ripgrep ffmpeg build-essential
# ============================================================================

# ----------------------------------------------------------------------------
